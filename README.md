### 🔭 What I'm Building

I am currently working full-time on a Project, **Evo**. Evo is a application that oversees everything you do and later helps you get back into work within a second, without ever having to manually open anything again. Under the hood, it is powered by a local-first context-memory engine built in Rust and SQLite, processing 1,000+ daily events at sub-100ms latency. I made a deliberate product trade-off to prioritize user trust and data ownership by utilizing a zero-cloud-dependency architecture.
